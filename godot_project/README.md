# Mi Mundo de Aventuras — Demo 01

Primera base de un videojuego educativo 3D para Android, creado en Godot 4.x.

## Incluye en esta base
- Pantalla inicial para escribir el nombre y elegir niña/niño.
- Habitación 3D sencilla creada con geometría básica.
- Personaje y gato representados por modelos provisionales 3D.
- Movimiento del personaje con WASD/flechas y controles táctiles en pantalla.
- Cuatro áreas educativas: sumas, restas, multiplicaciones y ortografía.
- Generación aleatoria de ejercicios y variedad de formatos.
- Corrección amable, monedas, estrellas y progreso guardado localmente.
- Estructura preparada para ampliar baño, living, cocina y patio.

## Abrir el proyecto
1. Instala Godot 4.x en un computador.
2. Descomprime este ZIP.
3. En Godot, importa el archivo `project.godot`.
4. Ejecuta el proyecto con F6/F5.

## Controles de escritorio
- WASD o flechas: mover el personaje.
- El menú permite entrar a cada actividad.
- Los botones táctiles aparecen en pantalla para probar la idea en móvil.

## Importante
Este es un prototipo inicial con modelos 3D geométricos provisionales, no arte final. No es todavía un APK compilado ni una versión probada en un teléfono. La siguiente fase será importar modelos 3D bonitos, mejorar las animaciones y probar exportación Android.
